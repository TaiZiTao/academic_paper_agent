# 论文翻译图表过滤设计

## 目标

章节翻译只展示正文与公式，暂时跳过图片、表格、图注、表注以及图表内部被 PDF 提取出的标签噪声。

## 方案

采用双层、可逆过滤：

1. 后端在构造翻译提示词前清理原文，避免把图表噪声发送给 LLM。
2. 前端在渲染历史译文前执行同一类清理，使已经保存的译文立即改善；不改写数据库。
3. 翻译提示词增加“跳过图表与图表内部文字”的兜底约束。

## 识别边界

- 以 `Fig.`、`Figure`、`Table`、`图 N`、`表 N` 以及 `(a)`、`(b)` 等图注信号定位图表区域。
- 只在图注附近清理连续短行、逆序单词、孤立变量和重复网络模块标签。
- 完整自然语言段落、章节标题和编号公式不作为噪声删除。
- 无法可靠判断时保留原文，优先避免误删正文。

## 数据流

`PDF 章节文本 → 图表噪声过滤 → 翻译分块 → LLM 翻译 → 保存译文`

历史数据展示路径为：

`已保存译文 → 显示过滤 → 公式解析/KaTeX → 页面`

## 测试

- 包含 PromptSR 图 2 标签与图注的样例应只留下前后正文。
- 正常正文、章节标题和公式应完整保留。
- 没有图表的内容应保持不变。
- 前端测试、后端翻译测试和生产构建均需通过。

## 非目标

- 本次不重新解析 PDF，不修改数据库中的历史译文。
- 本次不提供图片或表格翻译开关。

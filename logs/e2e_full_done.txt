==== FULL DONE 1: PGDUN 的 PGSA 模块怎么实现 ====
Multiple lightweight image super-resolution methods address the trade-off between global context modeling and local detail preservation through distinct architectural innovations. Neighborhood-constrained attention (NCA) explicitly preserves spatial structure by avoiding flattening-induced information loss and employs grid partitioning with local feature constrained attention (LFCA) blocks to maintain neighborhood integrity (Neighborhood constrained attention for lightweight image super-resolution, 3.2. Neighborhood constrained transformer block, p5; 3.1.1. Linear manner neighborhood labeling, p4). AMCANet introduces architecture-guided multi-head convolutional attention, where varied downsampling ratios across heads enable dynamic, multi-scale receptive fields—allowing efficient distribution of attention from local to non-local contexts while preserving information integrity via residual connections (AMCANet: A Lightweight Architecture-guided Multi-head Convolution Attention Network for Efficient Image Super-Resolution, 1.Introduction, p2; 3.2. Architecture-guided Multi-head Convolution, p4–p5). The lightweight multi-window attention transformer uses hierarchical window expansion and a serial sparse-to-channel fusion strategy (HSCA), demonstrating that joint sparse spatial sampling and channel-wise interaction—rather than parallel or channel-only variants—significantly improves high-frequency detail recovery and stabilizes training (A lightweight multi-window attention transformer for image super-resolution, 4.3.2. Effectiveness of HSCA in deep large windows, p8; 3.2.3. Window-adaptive multi-scale convolutional feed-forward network, p5). Dual-domain Modulation Network synergistically combines self-attention (for long-range global texture coherence) and dynamic convolution (for adaptive low-frequency detail refinement), confirming their complementary roles in restoring both global structure and fine-grained local features (Dual-domain Modulation Network for Lightweight Image Super-Resolution, C. Ablation Studies, p8; B. Spatial-domain Modulation Transformer, p5). Finally, PromptSR introduces cascade prompting with global anchor prompts (APs) generated via cross-attention over downsampled features, explicitly enlarging the receptive field beyond local windows and enabling coarse-to-fine, global-to-local token interactions—thereby overcoming the inherent limited receptive field of window-based Transformers (PromptSR: Cascade Prompting for Lightweight Image Super-Resolution, Methods, p3–p4). Collectively, these works converge on hybrid mechanisms—spatial-channel fusion, multi-head convolutional attention, dual-domain modulation, and global prompting—that jointly mitigate the flattening-induced spatial loss and insufficient high-frequency modeling observed in prior methods.

PGDUN 的 PGSA 模块未在所提供的五篇论文中被提及或定义。所有论文均未出现 'PGDUN' 或 'PGSA' 这一术语；相关轻量级超分辨率方法分别命名为 DMNet（Dual-domain Modulation Network）、PromptSR、AMCANet、NCA（Neighborhood constrained attention）和 lightweight multi-window attention transformer，但无任何文献描述、实现或引用 PGDUN/PGSA。证据库中全部段落均未包含该缩写、全称或对应结构说明，亦无等效模块的功能映射（如无‘prompt-guided spatial attention’、‘progressive global–local self-attention’等表述）。因此，当前论文集无法支持对 PGDUN 的 PGSA 模块的实现机制进行综述性回答。
